04 / WRITING

Mulai dari
tujuan.

Catatan tentang menyusun isi portofolio, menampilkan karya, membangun tampilan, dan belajar teknologi yang mendukung website.

TUJUAN KARYA TAMPILAN GITHUB CLOUDFLARE

01 / ARAH

Awalnya saya mulai dari tujuan website itu dibuat.

Saya memikirkan siapa yang akan melihat portofolio ini dan apa yang ingin mereka ketahui tentang saya. Jawabannya membantu saya menentukan isi profil, karya yang ditampilkan, serta gaya tampilan yang sesuai.

02 / CERITA

Isi karya harus punya cerita, bukan hanya daftar proyek.

Untuk setiap karya, saya ingin menjelaskan masalahnya, apa yang saya buat, dan hal yang saya pelajari. Dengan begitu, orang bisa mengenal proses berpikir di balik hasilnya, bukan hanya melihat gambarnya.

03 / DESAIN

Tampilan yang sederhana tetap bisa punya karakter.

Setelah tujuan dan isi karya lebih jelas, saya menyusun layout yang rapi, memilih warna yang konsisten, dan menjaga elemen visual tetap mudah dibaca. Saya ingin website terasa profesional sekaligus mencerminkan diri saya.

04 / TEKNOLOGI

GitHub membantu menyimpan dan mengembangkan kode.

GitHub dapat menyimpan kode secara online, mencatat perubahan, dan membantu beberapa orang berkolaborasi dalam satu proyek. Saya sedang belajar memahami manfaatnya untuk mengelola proyek website.

05 / TEKNOLOGI

Cloudflare membantu website tetap cepat dan terlindungi.

Saya mengenal Cloudflare sebagai layanan yang menyediakan DNS, CDN, koneksi HTTPS, dan perlindungan tambahan. Teknologi seperti ini membantu website lebih mudah diakses dan dikelola.
